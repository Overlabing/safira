# Onboarding

Tree read at each of the six steps (French). Reading order on every step: step counter, heading, text, controls, Back,
Continue or Finish.

| Control | Label | Role | Focusable | Result | By hand |
|---|---|---|---|---|---|
| Step counter | Étape 1 sur 6 … 6 sur 6 | text | n/a | pass | owed |
| Title | Bienvenue dans Safira, Créez votre premier profil, … | heading | n/a | pass | owed |
| Name, Symbol | titled by Nom, Symbole | text field | yes | pass | owed |
| Search engine list | Moteur de recherche; rows DuckDuckGo … Ecosia; selected trait on the chosen row | outline | yes | pass | owed |
| Shortcut preset list | Préréglage de raccourcis; rows Zen, Arc, Safari | outline | yes | pass | owed |
| Default browser button | Faire de Safira le navigateur par défaut… | button | no (Return) | pass | owed |
| Defaults list | Choix par défaut; rows read “title, value”, help is the explanation; switches are checkboxes with value 0 or 1 | outline | yes (Space flips the selected switch) | pass | owed |
| Back, Continue, Finish | Précédent, Continuer, Terminer; Continue disabled until a search engine is chosen | button | no (Return, Escape) | pass | owed |
