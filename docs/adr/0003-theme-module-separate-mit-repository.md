# The theme module lives in its own MIT repository

The color and theming code is shared with Oisillon, a closed-source app distributed through the App Store. Safira is GPL-3.0, so the module cannot live in Safira's repository without forcing Oisillon to go GPL. It is a separate MIT repository under the Overlabing organisation, and both apps depend on it. The module speaks only of Themes, never of Spaces, because the word means different things in the two apps.
