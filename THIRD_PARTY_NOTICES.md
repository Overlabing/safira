# Third-party notices

Safira is licensed under GPL-3.0-only (see `LICENSE`). This file reproduces the licence notice of every third-party
component that ships inside Safira.

Safira contains no third-party code yet.

When a dependency is added, its full licence notice goes here. The dependencies planned for v1 are GRDB.swift (MIT),
Sparkle (MIT, with BSD and zlib components) and ThemeKit, Safira's theme module, kept in its own MIT repository
(`docs/adr/0003-theme-module-separate-mit-repository.md`).
